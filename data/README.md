# Dados e premissas

O enunciado define a malha 8x8, os obstaculos, a origem/destino, os tempos medios M1/M2, o horizonte, a capacidade do caminhao e os universos do sistema fuzzy. Nao fornece custos/capacidades individuais da frota, coordenadas/demandas dos seis blocos ou leituras reais de sensores.

Os valores complementares do projeto sao **dados sinteticos para demonstracao didatica**. Nao representam dados operacionais da construtora, fornecedores comerciais reais, SINAPI ou CUB.
